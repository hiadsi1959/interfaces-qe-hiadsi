The website https://hiadsi1959.github.io/interfaces-qe-hiadsi/ offers an integrated suite of 5 physics web interfaces based on the Quantum ESPRESSO code. Designed to simplify and speed up the daily work of materials science researchers, this platform covers the entire ab initio workflow:

  • QE Input Generator — simplified creation of input files
  • Pseudopotential Database — search and selection
  • QE Calculation Interface — DFT/DFPT execution and tracking
  • thermo_pw Interface — thermodynamic and elastic properties
  • Supra-QE Interface — superconductivity and electron–phonon coupling

Getting started

Install an interface

Three steps on Ubuntu. Each interface then opens in your web browser.

Download

Get the .tar.gz archive for the interface you need from this site.

Extract

Unpack the file in your home directory, then open the folder that was created.

Start

Run the setup script once, then use ./DEMARRER.sh every time you start a session.

Example — Interface-QE v1

tar -xzf Interface-QE_v1.tar.gz
cd Interface-QE_v1
./CONFIGURER-PC.sh
./DEMARRER.sh
# → http://127.0.0.1:5007/interface/

Context

For researchers

These interfaces run on your own computer, with Quantum ESPRESSO installed locally. This website is only a showcase and download page — it does not run calculations online. Typical requirements: Ubuntu 20.04 or later, Python 3.9+, Quantum ESPRESSO 7.x.
