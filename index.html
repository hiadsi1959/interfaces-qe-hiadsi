Mise en route

Installer une interface

Trois étapes sur Ubuntu. Chaque interface s’ouvre ensuite dans le navigateur.

Télécharger

Récupérez l’archive .tar.gz de l’interface souhaitée depuis ce site.

Extraire

Décompressez le fichier dans votre dossier personnel, puis ouvrez le dossier obtenu.

Démarrer

Lancez le script de configuration (une fois), puis ./DEMARRER.sh à chaque session.

Exemple — Interface-QE v1

tar -xzf Interface-QE_v1.tar.gz
cd Interface-QE_v1
./CONFIGURER-PC.sh
./DEMARRER.sh
# → http://127.0.0.1:5007/interface/
