Six specialized interfaces for materials science

This platform brings together 6 computational web interfaces designed to simplify, automate, and enrich everyday research in materials science and condensed-matter physics — from input preparation to phonon transport and superconductivity. All tools run locally on your computer with Quantum ESPRESSO installed.

Cette plateforme regroupe 6 interfaces de calcul spécialisées, conçues pour simplifier, automatiser et enrichir le travail des chercheurs en sciences des matériaux et en physique de la matière condensée. Elles couvrent l’ensemble du parcours ab initio autour de Quantum ESPRESSO — et, pour la dynamique de réseau anharmonique, ALAMODE.

  1. 01 Générateur d’inputs QE

    Description. Interface intuitive pour préparer rapidement les fichiers d’entrée (.in de Quantum ESPRESSO (v7.x / 7.5+), y compris à partir de structures CIF.

    Fonctionnalités clés. Validation des paramètres, gestion des structures cristallines, génération de jeux d’inputs pour divers types de calculs (scf, nscf, bands, dos, relax, etc.).

  2. 02 Génération & base de pseudopotentiels

    Description. Unité centralisée pour rechercher, sélectionner et générer des pseudopotentiels adaptés à vos calculs DFT.

    Fonctionnalités clés. Accès aux principales bibliothèques (PSLibrary, PseudoDojo, SSSP…), prise en charge de formats variés (PAW, USPP, ONCVPSP, relativiste / non relativiste), filtres par élément et contrôles de compatibilité.

  3. 03 Interface de calcul QE

    Description. Environnement d’exécution et de suivi des calculs DFT (Density Functional Theory) et DFPT (Density Functional Perturbation Theory).

    Fonctionnalités clés. Lancement des modules (pw.x, ph.x, …), suivi de la convergence (énergie, forces), gestion des jobs et visualisation / analyse des sorties.

  4. 04 Interface thermo_pw

    Description. Outil dédié aux propriétés thermodynamiques et élastiques des matériaux en fonction de la température et de la pression (routines thermo_pw).

    Fonctionnalités clés. Constantes élastiques, vitesses du son, température de Debye, capacité calorifique, expansion thermique, phonons et constantes diélectriques.

  5. 05 Interface Supra-QE

    Description. Plateforme axée sur la supraconductivité conventionnelle et le couplage électron–phonon.

    Fonctionnalités clés. Fonction spectrale d’Eliashberg α²F(ω), constante de couplage λ, estimation de la température critique Tc (Allen–Dynes / McMillan), et voie EPW / Eliashberg.

  6. 06 Interface QE–ALAMODE

    Description. Interface hybride associant Quantum ESPRESSO (forces DFT, supercellules) aux méthodes d’anharmonicité d’ALAMODE pour la dynamique de réseau et le transport thermique.

    Fonctionnalités clés. Constantes de force interatomiques (IFC, NORDER≥2), dispersion de phonons, conductivité thermique de réseau κL (RTA), et export de fiche technique pour l’analyse des résultats.

This platform brings together 6 specialized computational interfaces designed to streamline, automate, and enhance research workflows in materials science and condensed-matter physics. Together they cover the full ab initio path around Quantum ESPRESSO — and, for anharmonic lattice dynamics, ALAMODE.

  1. 01 QE Input Generator

    Description. An intuitive interface for the rapid setup of Quantum ESPRESSO (v7.x / 7.5+) input files (.in), including CIF → input conversion.

    Key features. Parameter validation, crystal-structure handling, and fast generation of input sets for scf, nscf, bands, dos, relax, and related calculation types.

  2. 02 Pseudopotential Generator & Database

    Description. A centralized tool to search, select, and generate pseudopotentials for DFT calculations.

    Key features. Access to major libraries (PSLibrary, PseudoDojo, SSSP, …), support for PAW, USPP, ONCVPSP (relativistic / non-relativistic), element filters, and compatibility checks.

  3. 03 QE Calculation Interface

    Description. An execution and monitoring environment for DFT and DFPT simulations.

    Key features. Launch of core modules (pw.x, ph.x, …), tracking of energy/force convergence, job management, and rapid parsing / visualization of outputs.

  4. 04 thermo_pw Interface

    Description. A dedicated workflow for thermodynamic and elastic properties under varying temperature and pressure, driven by thermo_pw.

    Key features. Elastic constants, sound velocities, Debye temperature, heat capacity, thermal expansion, phonons, and dielectric constants.

  5. 05 Supra-QE Interface

    Description. An analysis module focused on conventional superconductivity and electron–phonon coupling.

    Key features. Eliashberg spectral function α²F(ω), coupling constant λ, critical temperature Tc (Allen–Dynes / McMillan), and the EPW / Eliashberg route.

  6. 06 QE–ALAMODE Interface

    Description. A hybrid interface coupling Quantum ESPRESSO (DFT forces, supercells) with ALAMODE’s anharmonic solvers for lattice dynamics and heat transport.

    Key features. Interatomic force constants (IFCs, NORDER≥2), phonon dispersions, lattice thermal conductivity κL (RTA), and technical-sheet export for result analysis.

Author: Prof. S. HIADSI — LMESM / Faculty of Physics / USTO-MB, Oran, Algeria. Free to use for research and teaching; modifying the source code requires collaboration with the author.

The website https://hiadsi1959.github.io/interfaces-qe-hiadsi/ offers an integrated suite of 6 physics web interfaces based on the Quantum ESPRESSO code (and ALAMODE for anharmonic phonons). Designed to simplify and speed up the daily work of materials science researchers, this platform covers the entire ab initio workflow:

  • QE Input Generator — simplified creation of input files
  • Pseudopotential Database — search and selection
  • QE Calculation Interface — DFT/DFPT execution and tracking
  • thermo_pw Interface — thermodynamic and elastic properties
  • Supra-QE Interface — superconductivity and electron–phonon coupling
  • QE–ALAMODE Interface — anharmonic phonons and lattice thermal conductivity (QE + ALAMODE)

Getting started

Install an interface

Three steps on Ubuntu. Each interface then opens in your web browser.

Download

Get the .tar.gz archive for the interface you need from this site.

Extract

Unpack the file in your home directory, then open the folder that was created.

Start

Run the setup script once, then use ./DEMARRER.sh every time you start a session.

Example — Interface-QE v1

tar -xzf Interface-QE_v1.tar.gz
cd Interface-QE_v1
./CONFIGURER-PC.sh
./DEMARRER.sh
# → http://127.0.0.1:5007/interface/

Example — QE–ALAMODE

tar -xzf QE-Alamode_interface.tar.gz
cd QE-Alamode_interface
source /opt/intel/oneapi/setvars.sh   # required for bundled alm/anphon
./INSTALLER_AUTRE_PC.sh
./DEMARRER.sh
# → http://127.0.0.1:5020/
