An integrated suite of 5 interfaces

Designed to cover the full ab initio workflow based on Quantum ESPRESSO: input generation, pseudopotentials, DFT/DFPT execution, thermodynamic properties, and electron–phonon coupling.

  1. 01QE Inputssimplified file creation
  2. 02Pseudopotentialssearch and selection
  3. 03QE CalculationsDFT / DFPT and tracking
  4. 04thermo_pwelasticity & thermodynamics
  5. 05Supra-QEsuperconductivity & e–ph

Built for materials science researchers who want a clearer, faster path through everyday Quantum ESPRESSO workflows — locally on their own computer.

Getting started

Install an interface

Three steps on Ubuntu. Each interface then opens in the browser.

Download

Get the .tar.gz archive for the interface you need from this site.

Extract

Unpack the file in your home directory, then open the resulting folder.

Start

Run the configuration script once, then ./DEMARRER.sh for each session.

Example — Interface-QE v1

tar -xzf Interface-QE_v1.tar.gz
cd Interface-QE_v1
./CONFIGURER-PC.sh
./DEMARRER.sh
# → http://127.0.0.1:5007/interface/

Context

For researchers

These interfaces run on your computer with Quantum ESPRESSO installed. This site is a showcase and download repository — not remote computing. Typical requirements: Ubuntu 20.04+, Python 3.9+, QE 7.x.
